# 48-hour team plan

## Goal

Help an FBO manager see how many workers may be needed, test busy-day problems, and review a draft schedule.

## Five people, five tasks

| Member | Do this | Finish with |
|---|---|---|
| 1. Arrivals data | Look for public aircraft arrival counts for LA airports. If the data is not useful, use our generated sample. Mark which numbers are public and which are made up. | A clear note on where the arrival numbers came from. |
| 2. Work times | Ask an aviation mentor how long common jobs may take. Let the manager change those times in the app. Mark unconfirmed times as guesses. | Editable job times with guesses labeled. |
| 3. Staff schedule | Use sample workers, their skills, and when they can work. Make a draft schedule. Show any work with no worker available. | A draft weekly schedule and a list of uncovered work. |
| 4. Busy-day tests | Add controls for extra arrivals, slower work, and workers calling out. Compare the starting schedule and suggested schedule with the same busy-day problems. | Buttons to test problems and a fair comparison. |
| 5. Connect and demo | Connect everyone's work. Run the app and checks. Get mentor feedback. Practice the demo. | A working demo and a short pitch. |

## Timing

- **Hours 0–2:** Agree on what data each part needs.
- **Hours 2–20:** Work on tasks at the same time.
- **Hours 20–32:** Connect the parts.
- **Hours 32–42:** Test the app and ask a mentor to check the assumptions.
- **Hours 42–48:** Stop adding features. Practice the demo.

## Demo checklist

- Show a normal week and low, medium, and high event weeks.
- Show the draft staff schedule and uncovered work.
- Test extra arrivals and worker call-outs.
- Compare both schedules using the same test.
- Have the manager review the plan. The app must not dispatch workers or control aircraft.

## Simple meanings

- **Made-up data:** example data created for the demo; not real FBO records.
- **Starting schedule:** the simple schedule used for comparison.
- **Suggested schedule:** the schedule the app recommends.
- **Uncovered work:** jobs with no available worker in the schedule.

Keep this project about staffing. Do not claim made-up data proves real accuracy or savings.
